# Интерактивная ширма мастера

Настольный рабочий стол ведущего D&D для Windows, Linux и macOS. В ширме есть трекер боя, музыка, справочник dnd.su, карта и листы Long Story Short.

## Скачать

Скачайте сборку для своей системы из [последнего выпуска на GitHub](https://github.com/Vilsonchik-Jmixus/interactive-dm-screen/releases/latest).

| Система | Что скачать |
| --- | --- |
| Windows x64 | `DM-Screen-Setup-<версия>.exe` |
| Linux x64 или ARM64 | `DM-Screen-<версия>-linux-<архитектура>.deb` для Debian и Ubuntu или одноимённый `.AppImage` для других дистрибутивов |
| macOS | `DM-Screen-<версия>-mac-arm64.dmg` для Apple Silicon (M1 и новее) или `DM-Screen-<версия>-mac-x64.dmg` для Intel |

На Linux пакет `.deb` можно установить командой `sudo apt install ./имя-файла.deb`. Для AppImage сделайте загруженный файл исполняемым (`chmod +x имя-файла.AppImage`). AppImage использует FUSE 2.

На macOS откройте DMG и перетащите приложение в «Программы». Сборка подписана локальной подписью и не проходила нотарификацию Apple. Если macOS заблокирует запуск, см. [справку Apple по открытию приложений](https://support.apple.com/ru-ru/102445).

На Linux и macOS для импорта по ссылке YouTube нужен FFmpeg с кодеком MP3. Установите его через менеджер пакетов, например `sudo apt install ffmpeg` на Debian и Ubuntu или `brew install ffmpeg` на macOS. Windows-версия включает FFmpeg. Локальные аудиофайлы можно добавлять сразу на всех платформах. На Mac для вставки изображения используйте ⌘V.

## Возможности

- Карта занимает всю высоту в центре. Слева находятся трекер и музыка, справа — листы, галерея, заметки и справочник. Ширина колонок и высота боковых панелей регулируются разделителями.
- В раскладке **Подготовка** в центре открываются заметки и быстрый выбор сцены. В режиме **Игра** в центр возвращается карта. Размеры панелей хранятся отдельно для каждой раскладки в кампании.
- При запуске ширма открывается на весь экран. F11 или кнопка ⛶ в шапке переключают полноэкранный и оконный режимы.
- В меню **Сцены** можно собрать карту, бой, музыкальный трек и заметку и открыть их одним щелчком.
- При перетаскивании жетона линейка показывает длину маршрута в футах. **F** запоминает точку маршрута, **Alt+F** убирает последнюю, **Esc** отменяет ход. В настройках сетки можно выбрать стоимость диагоналей. Обычная клетка равна 5 футам.
- Кнопка **↶** или **Ctrl+Z** на карте (**⌘Z** на Mac) отменяет последние действия на текущей карте. История хранится на время работы с кампанией.
- В редакторе карты **＋ Заметка** размещает метку из сюжетной доски. Метки видны мастеру. Щелчок выделяет карточку на доске, правый щелчок позволяет снять метку.
- **◈** рядом со списком карт открывает предпросмотр экрана игроков. При открытом окне игроков предпросмотр учитывает его размеры, туман, иллюстрации и затемнение.
- В меню **Кампании** можно создать отдельную кампанию или перенести её вместе с медиа в архиве `.tar.gz`. Импорт создаёт отдельную копию. При переключении кампании открытый экран игроков прикрывается.
- Через ⚙ **Оформление и звук** можно выбрать «Таверну» или одну из семи приглушённых тёмных тем. Выбор сохраняется для всех окон ширмы. Значок запущенного окна меняет цвет. В Windows на закреплённом значке цвет темы также показывает маленькая накладка.
- Вкладка «Заметки» рядом с галереей открывает сюжетную доску. Карточки растут по высоте и показывают весь текст. В редакторе карточки можно вставить картинку через Ctrl+V или ⌘V, выбрать файл или перетащить его. Перемещайте карточки за заголовок и протягивайте связи от точки на краю. Для перемещения доски тяните за пустое поле или удерживайте колесо мыши. Кнопка «К заметкам» возвращает к первой карточке. Заметки, связи, изображения и рисунки сохраняются вместе с кампанией.

- Бойцы: имя, портрет, ХП, инициатива, дублирование, очередь ходов и раунды.
- В карточке выберите «Персонаж игрока», «Союзник» или «Противник». У противника можно заранее сохранить бонус инициативы. Кнопка с числом или «—» позволяет вписать инициативу вручную. d20 в карточке бросает за одного противника. Меню «Инициатива» бросает отдельно за каждого противника с его бонусом или сбрасывает значения, ручную очередь и счётчик раундов текущего боя.
- В трекере можно искать участников по имени и фильтровать по стороне.
- Текущий участник закреплён над списком. Кнопки −5, −1, +1 и +5 меняют его ХП и работают с общей отменой. В редакторе состояний можно задать оставшиеся раунды. В конце раунда таймер уменьшается, а по его истечении состояние снимается.
- В редакторе участника портрет можно вставить через Ctrl+V или ⌘V, перетащить из проводника либо выбрать файл. Импорт JSON Long Story Short добавляет персонажа вместе с портретом, если картинка встроена в экспорт.
- Стрелки ↑ и ↓ переставляют бойцов вручную, а ⇅ возвращает сортировку по инициативе. При ручной очереди новый бросок обновляет число инициативы, сохраняя порядок. Счётчик раунда показывает номер и число завершённых ходов. Новый раунд начинается, когда каждый боец сходил.
- Назначайте [15 состояний D&D 5e](https://dnd.su/articles/mechanics/27-conditions/) через ◆ в карточке или правый щелчок по жетону. Метки видны в трекере и на карте. Истощение имеет 6 уровней. При 0 ХП ширма добавляет автоматическую отметку «Бессознательный» и снимает её после лечения. Состояния отображаются как метки. Их влияние на правила применяет мастер.
- В трекере есть список подготовленных боёв. Нажмите «＋», задайте имя и добавьте участников. Каждый бой сохраняет свои ХП, инициативу, раунд, текущий ход и историю отмены. В «⋯» можно указать карту, которая откроется вместе с боем.
- В «Заготовках» можно подготовить персонажей и добавлять их копии в бой или сразу на карту. Чтобы поставить жетон, нажмите «На карту» и выберите клетку либо перетащите карточку участника. Backspace убирает выбранный жетон. Повторное нажатие «На карте» запрашивает подтверждение. Shift + щелчок по этой кнопке показывает жетон.
- Откройте **✎ Редактор карты** в её заголовке. Потяните мышью, чтобы провести стену, дверь или окно, либо задайте радиус света. Окно ставится в проёме, блокирует проход и пропускает обзор или свет, когда до окна не больше одной клетки. Дверь в обычном режиме открывается щелчком по её значку. Через **＋ Предмет** можно подписать метку, загрузить или перетащить свою иконку и выбрать клетку.
- В редакторе карты выберите «Карандаш», чтобы рисовать поверх карты. Можно менять цвет и толщину. «Ластик» удаляет щелчком штрихи, стены, двери, окна и источники света. Выберите тип в списке, если рядом несколько объектов. Рисунки сохраняются отдельно для каждой карты и появляются в окне игроков после завершения штриха.
- Туман можно включить при создании карты, кнопкой ☁ или клавишей F, когда карта в фокусе. В окне мастера он полупрозрачный. Персонажи игроков и союзники с положительным ХП открывают обзор на 60 футов (12 клеток). Кнопка **↺ Туман** рядом со списком карт сбрасывает историю исследования текущей карты и оставляет видимым текущий обзор жетонов.
- Перетащите ссылку существа из бестиария dnd.su в трекер, а ссылку магического предмета — на клетку карты. Ширма берёт иллюстрацию, когда она есть в карточке. JSON-экспорт Long Story Short можно бросить в трекер или открыть через «LSS ↧». Он переносит имя, ХП, бонус инициативы и вложенный портрет.
- Изменение ХП: `-7`, `+5`, `=20`. Нажмите на число ХП или карандаш, чтобы изменить текущие и максимальные ХП. Кнопка «↶ ХП» отменяет изменение здоровья и его максимума.
- Кнопка «На карту» позволяет выбрать клетку для жетона. Двойной щелчок по жетону открывает подтверждение снятия с карты. Backspace снимает выбранный жетон.
- Карта из файла, перетаскивания или буфера обмена (`Ctrl+V`). Потяните свободный участок для перемещения, нажмите ⊡ для обзора целиком или кнопку «На карте» для перехода к жетону.
- Список в панели карты позволяет заранее создать несколько локаций. У каждой своё изображение, масштаб, сетка и позиции жетонов. Чтобы поставить участников, выберите нужный бой и карту, затем нажмите «На карту» в карточках. Переключение карты оставляет активный бой. Если один участник размещён на нескольких картах, его ХП общие для всех его жетонов.
- Через «⋯» можно переименовать или скопировать заготовку. Копия боя получает новый состав из тех же участников с полными ХП и первым раундом. Копия карты получает изображение, сетку и рисунки, а жетоны можно расставить заново.
- Кнопка ↗ на карте открывает экран игроков. Перетащите его на второй монитор и нажмите F11 для полного экрана. Мастер продолжает двигать и масштабировать карту в ширме. Игроки видят это движение и перетаскивание жетонов в реальном времени.
- Shift + щелчок по карте ненадолго подсвечивает точку. Кнопка ◉ открывает настройки экрана игроков. Здоровье персонажей игроков и союзников видно по умолчанию. Числа ХП противников доступны только мастеру. Существующие бойцы без выбранной роли считаются противниками, пока мастер не изменит роль.
- Окно игроков по умолчанию заполняется картой целиком при разворачивании. В настройках экрана игроков можно выбрать сохранение пропорций или следование за камерой мастера. Там же задаётся отдельная ориентация для игроков. Поворот доступен в самом окне игроков через кнопки в шапке или Shift+← и Shift+→. Настройка сохраняется для каждой карты и видна в предпросмотре.
- В правой панели переключитесь с «Листов» на «Галерею». Добавляйте иллюстрации из файла, перетаскиванием или через Ctrl+V. Выбор кадра открывает предпросмотр у мастера. «Показать игрокам» выводит изображение во второе окно, а «Карта игрокам» возвращает карту с прежней позиции. Рядом есть недавно показанные кадры.
- Нажмите на портрет в карточке бойца, чтобы открыть его для себя или показать игрокам. F11 разворачивает окно игроков, а Escape возвращает его в оконный режим.
- Трекер, музыка и браузерные панели выносятся в отдельные окна. Закрытие окна возвращает соответствующую панель.
- Изменение раскладки разделителями и уголком панели. Разворачивание с анимацией, кнопка ⛶, Escape. Если дотянуть уголок до нижнего правого края рабочей области, панель развернётся. Размер отдельного окна можно менять за его границы. F11 включает полный экран.
- dnd.su и Long Story Short работают как изолированные браузерные панели. Вход выполняется на самом сайте; браузерная сессия сохраняется. Провайдер входа может ограничивать авторизацию во встроенных браузерах — предусмотрена кнопка открытия сайта в обычном браузере; его сессия с приложением не общая.
- В справочнике, веб-поиске и Long Story Short удерживайте Ctrl и прокручивайте колесо над страницей, чтобы изменить её масштаб. После щелчка по странице работают также Ctrl+плюс, Ctrl+минус и Ctrl+0 для возврата к 100%. На macOS можно использовать ⌘.
- В справочнике есть быстрые ссылки на классы, расы, заклинания, бестиарий, доспехи, оружие, снаряжение, магические предметы и состояния. Поле поиска с вкладки dnd.su ищет по сайту через DuckDuckGo. На вкладке «Веб» можно искать по интернету и вводить HTTPS-адреса. ★ сохраняет готовые страницы в закладки. Gemini открывается в обычном браузере, а введённый вопрос копируется для вставки.
- Музыка: локальные файлы и импорт MP3 по ссылке YouTube. yt-dlp загружает аудиодорожку, FFmpeg преобразует её в MP3, и трек сразу появляется в выбранной папке. Процесс показывает прогресс и поддерживает отмену. Уже сохранённые записи используются повторно без скачивания. Скорость скачивания зависит от сети и доступности ролика.
- Кампания и медиа автоматически сохраняются в `%APPDATA%/interactive-dm-screen`. Они отделены от установки и не удаляются при обновлении.

Каждая кампания хранит свои бои, карты, заметки и медиа. После обновления существующие данные доступны в «Первой кампании». Резервная копия старого формата хранится рядом с кампанией в `campaign.json.v1.bak`. После нового запуска панели сначала находятся в ширме.

## Разработка

Нужны Node.js 24 и npm. Встроенные сайты и загрузчик требуют интернет. Трекер, карта и импортированные треки работают локально.

```powershell
npm ci --ignore-scripts
node node_modules/electron/install.js
npm run tools
npm start
```

Проверка логики и сборка:

```powershell
npm test
node tests/desktop-smoke.cjs
node tests/workspace-smoke.cjs
npm run build
```

Интерфейс работает на Electron с HTML/CSS/JS. Изолированные WebContentsView для удалённых сайтов не имеют доступа к Node.js или API приложения. Главный процесс хранит кампанию в JSON и локальные медиа в папке assets. Сборщик проверяет SHA256 поставляемых копий yt-dlp и FFmpeg.

## Выпуск обновлений

Windows (NSIS) и Linux (AppImage) проверяют GitHub Releases при старте и каждые четыре часа. Кнопка «Обновления» запускает ручную проверку. Если вышла новая версия, можно скачать её и перезапустить ширму для установки. На macOS и в версии Linux из пакета `.deb` кнопка «Версии на GitHub» открывает страницу для ручного обновления.

```powershell
npm version patch
git push origin main --follow-tags
```

Workflow `.github/workflows/release.yml` запускается на тег `v*`, проверяет совпадение версии, выполняет тесты и публикует установщик, `.blockmap` и `latest.yml`. Не удаляйте эти файлы из выпуска: они нужны механизму обновлений. Репозиторий и выпуски должны оставаться публичными для обновления без пользовательского токена. `GH_TOKEN` используется только сборкой в GitHub Actions; в приложение секреты не включаются.
