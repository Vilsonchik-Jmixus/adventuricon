# Интерактивная ширма мастера

Настольный рабочий стол ведущего D&D для Windows. Пять панелей по исходному макету: трекер боя, музыка, dnd.su, карта и Long Story Short.

## Скачать

Откройте [последний выпуск](https://github.com/Vilsonchik-Jmixus/interactive-dm-screen/releases/latest), скачайте `DM-Screen-Setup-<версия>.exe` и установите программу. Установщик первой версии не имеет коммерческой цифровой подписи.

## Возможности прототипа

- Бойцы: имя, портрет, ХП, инициатива, дублирование, очередь ходов и раунды.
- В трекере есть список подготовленных боёв. Нажмите «＋», задайте имя и добавьте участников. Каждый бой сохраняет свои ХП, инициативу, раунд, текущий ход и историю отмены. В «⋯» можно указать карту, которая откроется вместе с боем.
- Изменение ХП: `-7`, `+5`, `=20`. Нажмите на число ХП или карандаш, чтобы изменить текущие и максимальные ХП. Кнопка «↶ ХП» отменяет изменение здоровья и его максимума.
- Кнопка «На карту»: жетон занимает свободную клетку; повторное добавление исключено. Перетаскивание привязывается к сетке; двойное нажатие убирает жетон.
- Карта из файла, перетаскивания или буфера обмена (`Ctrl+V`). Потяните свободный участок для перемещения, нажмите ⊡ для обзора целиком или кнопку «На карте» для перехода к жетону.
- Список в панели карты позволяет заранее создать несколько локаций. У каждой своё изображение, масштаб, сетка и позиции жетонов. Чтобы поставить участников, выберите нужный бой и карту, затем нажмите «На карту» в карточках. Переключение карты оставляет активный бой. Если один участник размещён на нескольких картах, его ХП общие для всех его жетонов.
- Через «⋯» можно переименовать или скопировать заготовку. Копия боя получает новый состав из тех же участников с полными ХП и первым раундом. Копия карты получает то же изображение и сетку, а жетоны можно расставить заново.
- Кнопка ↗ на карте открывает экран игроков. Перетащите его на второй монитор и нажмите F11 для полного экрана. Мастер продолжает двигать и масштабировать карту в ширме. Игроки видят это движение и перетаскивание жетонов в реальном времени.
- Shift + щелчок по карте ненадолго подсвечивает точку. Кнопка ◉ на карте открывает настройки экрана игроков: показ ХП и затемнение. По умолчанию ХП видит мастер.
- В правой панели переключитесь с «Листов» на «Галерею». Добавляйте иллюстрации из файла, перетаскиванием или через Ctrl+V. Выбор кадра открывает предпросмотр у мастера. «Показать игрокам» выводит изображение во второе окно, а «Карта игрокам» возвращает карту с прежней позиции. Рядом есть недавно показанные кадры.
- Нажмите на портрет в карточке бойца, чтобы открыть его для себя или показать игрокам. F11 разворачивает окно игроков, а Escape возвращает его в оконный режим.
- Трекер, музыка и браузерные панели выносятся в отдельные окна. Закрытие окна возвращает соответствующую панель.
- Изменение раскладки разделителями и уголком панели. Разворачивание с анимацией, кнопка ⛶, Escape. Если дотянуть уголок до нижнего правого края рабочей области, панель развернётся. Отдельные окна изменяют размер обычными границами Windows; F11 включает полный экран.
- dnd.su и Long Story Short работают как изолированные браузерные панели. Вход выполняется на самом сайте; браузерная сессия сохраняется. Провайдер входа может ограничивать авторизацию во встроенных браузерах — предусмотрена кнопка открытия сайта в обычном браузере; его сессия с приложением не общая.
- Музыка: локальные файлы и импорт MP3 по ссылке YouTube. yt-dlp загружает аудиодорожку, встроенный FFmpeg преобразует её в MP3, и трек сразу появляется в выбранной папке. Процесс показывает прогресс и поддерживает отмену. Уже сохранённые записи используются повторно без скачивания. Скорость скачивания зависит от сети и доступности ролика.
- Кампания и медиа автоматически сохраняются в `%APPDATA%/interactive-dm-screen`. Они отделены от установки и не удаляются при обновлении.

В одной локальной кампании можно хранить несколько боёв и карт. При обновлении с прежнего формата существующие бой и карта станут первыми заготовками. Резервная копия старого файла хранится рядом с кампанией в `campaign.json.v1.bak`. Расположение отдельных окон сохраняется. После нового запуска панели сначала находятся в ширме.

## Разработка

Нужны Windows x64, Node.js 24 и npm. Встроенные сайты и загрузчик требуют интернет; трекер, карта и импортированные треки работают локально.

```powershell
npm ci --ignore-scripts
node node_modules/electron/install.js
npm run tools
npm start
```

Проверка логики и сборка:

```powershell
npm test
node tests/desktop-smoke.cjs
npm run build
```

Архитектура: Electron, WebContentsView для удалённых сайтов, обычные HTML/CSS/JS для интерфейса, единый reducer в главном процессе и атомарное сохранение JSON. Удалённые сайты не имеют доступа к Node.js или API приложения. Локальные медиа копируются в управляемую папку assets. yt-dlp и FFmpeg поставляются отдельно от asar. Сборщик проверяет SHA256 обоих загрузочных архивов или файлов.

## Выпуск обновлений

В установленной NSIS-версии electron-updater проверяет GitHub Releases при старте и каждые четыре часа. Новая версия предлагается пользователю: скачать → перезапустить и установить. Автоматического закрытия игры нет. Кнопка «Обновления» запускает ручную проверку. В режиме разработки обновления отключены.

```powershell
npm version patch
git push origin main --follow-tags
```

Workflow `.github/workflows/release.yml` запускается на тег `v*`, проверяет совпадение версии, выполняет тесты и публикует установщик, `.blockmap` и `latest.yml`. Не удаляйте эти файлы из выпуска: они нужны механизму обновлений. Репозиторий и выпуски должны оставаться публичными для обновления без пользовательского токена. `GH_TOKEN` используется только сборкой в GitHub Actions; в приложение секреты не включаются.
